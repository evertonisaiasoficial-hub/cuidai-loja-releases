# Cuidaí Loja — instaladores

Este repositório guarda **só os instaladores** do Cuidaí Loja para Windows (64 bits). Não tem código.

- Baixar a versão mais nova: abra **Releases** (à direita) e baixe o arquivo `CuidaiLoja-Instalador-<versão>.exe`.
- Quem já tem o app instalado não precisa baixar de novo: o Cuidaí Loja se atualiza sozinho e instala a versão nova quando você fecha o app.
- Cada instalador vem com um arquivo `.sig` (assinatura digital). O app só aceita uma atualização se a assinatura conferir.
